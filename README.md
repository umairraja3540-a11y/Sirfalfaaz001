# Sirfalfaaz Website

A responsive Urdu poetry and emotional-stories website for **Sirfalfaaz**.

## Files
- `index.html` — website content and page structure
- `style.css` — dark VIP theme, gold accents, and responsive layout
- `script.js` — mobile navigation and automatic copyright year

## Run locally
Keep all three website files in the same folder, then open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository named `sirfalfaaz` (or another name you prefer).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's main/root folder. You can also upload this README.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. Wait for GitHub Pages to publish your site. The Pages section will show its website address.

Keep the filenames exactly as written and in the same folder so the page can load its styling and script.
